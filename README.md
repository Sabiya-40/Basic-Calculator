# Basic Calculator

A clean, responsive, and interactive Web Calculator built using HTML5, CSS3, and JavaScript.

---

## 🚀 Features

* Basic Operations: Supports addition (+), subtraction (-), multiplication (*), and division (/).
* Clear Function: Reset the screen anytime using the C button.
* Decimal Support: Performs calculations with decimal values.
* Interactive UI: Smooth button layouts designed using CSS Flexbox.

---

## 🛠️ Tech Stack

* HTML5: Structure and markup.
* CSS3: Styling, grid/flexbox layout, and button design.
* JavaScript (ES6): Dynamic UI updating and calculation logic.
